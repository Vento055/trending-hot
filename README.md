# trending-hot

Source code for **[trending-hot.com](https://www.trending-hot.com)** — an AI trend and developer-ecosystem signal site.

Every analysis is built from public signals (Google Trends, Reddit, Product Hunt, GitHub, Hacker News) and carries the evidence attached to it. **Filtered to signal, not noise** — no hype, every claim labeled with its sources.

- **Site:** https://www.trending-hot.com
- **Author:** Vento Lee — independent AI/tech analyst
- **Also from the same author:** [tuanzi-life-engine](https://github.com/Vento055/tuanzi-life-engine)

## Stack

Next.js 16 · React 19 · Tailwind v4 · deployed on Vercel.

## Where to start on the site

- [Today's signals](https://www.trending-hot.com/signals) — the daily shortlist
- [Guides](https://www.trending-hot.com/guides) — long-form trend guides
- [Inference](https://www.trending-hot.com/inference) — the LLM serving/cost cluster
- [Feed](https://www.trending-hot.com/feed.xml) — Atom feed of new analyses

## Running locally

```bash
npm install
npm run dev
```
